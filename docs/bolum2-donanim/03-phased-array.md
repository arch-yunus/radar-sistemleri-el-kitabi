# 2.3 Phased Array (Faz Dizili) Antenler

Mekanik hareket olmadan hüzme yönlendirme teknolojisi.

## Müfredat Başlıkları
* **Dizi Faktörü (Array Factor):** Anten elemanlarının geometrik dizilimi.
* **Faz Kaydırıcılar:** Elektronik olarak hüzme tarama mantığı.
* **AESA ve PESA Farkları:** Aktif ve pasif dizili sistemlerin karşılaştırılması.
